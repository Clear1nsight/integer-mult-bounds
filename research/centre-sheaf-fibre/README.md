# The full centre kernel on the 4080-owner block

**The common kernel has exactly one scalar dimension, even when all 112 ports
are allowed to vary.** The known PR3656 vector spans it. This answers that
PR's full-block kernel-dimension question in the centre-sharing lineage of
PR3147. It does not construct a faster centre or a multiplication supplier.

## Result

Let H be PR3656's subgroup generated by the even products of routes 0, 6,
and 85. Let S be the old eight-query observation at each owner and T the
later routed observation in the inherited calls-0/4 source model. Then

    ker S intersect ker T = Q v,

where v is (1,-1,-1) on ports (0,6,85) at every owner of H and zero elsewhere.
The proof uses all 112 ports, not just the three supported by the old witness.

| Quantity | Exact result |
| --- | ---: |
| Source owners | 4080 |
| Ports per owner | 112 |
| Source variables | 456960 |
| Old observation rank | 32640 |
| Kernel of the old observation | 424320 |
| Common kernel of old and later observations | 1 |
| Additional linear observations needed to recover all later queries | 424319 |

Every proper subset B of this particular H has zero common kernel, so its
additional linear-observation requirement is exactly 104 times |B|. This also
holds on left translates. It does not establish a 4080-owner floor for
arbitrary blocks, and the broader minimum-support question remains open.

For the integer map [S;4T], the kernel is Z v. Every nonnegative integer fibre
is an interval along the primitive move v. The move has 4080 positive and
8160 negative entries; fixing total coefficient count eliminates it. These
are coefficient fibres, not legal schedules or paid circuit operations.

## Why the unconventional pairing helps

A cellular sheaf expresses local zero-observation states and their edge
compatibility. Right-coset grouping eliminates 109 independent singleton
output classes. Only the rank-two triple (0,6,85) remains. Compatibility on
its connected graph forces a single constant amplitude across all owners.
The algebraic-statistics step then identifies the primitive integer fibre,
including the extra count constraint that defeats a naive resource exchange.

The reduction replaces a very large routed-matrix calculation with 110 small
column-rank certificates and one graph-connectivity check. See PROOF.md for
all hypotheses, exact consequences, source-model restrictions, and credit.

## Verification and reproduction

Two separately written implementations reconstruct the original archived
geometry. The primary reuses PR3071's authenticated extractor; independent.py
imports no primary or predecessor executable and uses a separate parser,
forward propagation, row-matrix algebra, modular minors, and direct residuals.
Both passed normal and optimised source-bound runs in the fork's existing
Python 3.12.15 workflow. This is same-session independent implementation, not
independent human or proof-kernel acceptance. See EVIDENCE.md for exact heads.

From a complete repository checkout:

```sh
python3.12 -B scripts/research_package.py --package research/centre-sheaf-fibre
```

From this directory alone, using its frozen derived geometry:

```sh
python3 -I -B verify.py --geometry GEOMETRY.json.gz
python3 -I -O -B independent.py --geometry GEOMETRY.json.gz
python3 -I -B test_sheaf.py
python3 -I -O -B controls.py
```

The compact export is sufficient for these latter commands, but intentionally
does not include the selected source archive. Such runs do not repeat archive
extraction. Default registered execution authenticates both source inputs and
compares the derived geometry with the bundled copy. The scientific receipt
is strictly compared, and all corruption controls use disposable copies.

## Scope and next decision

The source slice retains the first-call constant-source endpoint used by
PR3071/3147/3656. It is not arbitrary full native payload execution. Physical
acquisition, ownership, finite precision, phases, chronological restoration,
recursive prices, and a complete supplier remain separate obligations.

The known block has only its already exhibited one-dimensional freedom.
Repeating searches inside its proper subsets cannot yield another common
kernel. A useful changed question would involve genuinely different owner
blocks or observations, with an explicit cost allowance before construction.
TASK.json records the scope change and the family decision to stop this local
investigation rather than infer a paid saving from one invisible scalar.
